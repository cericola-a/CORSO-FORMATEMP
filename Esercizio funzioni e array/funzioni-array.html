La funzione restituisce un risultato utilizzando return.

4. Array con valori iniziali

6. Accesso all'array tramite indice

Possiamo leggere un elemento indicando la sua posizione.

La proprietà length indica quanti elementi contiene un array.

8. Copia di un array

Copiamo un array esistente utilizzando lo spread operator.

9. Modifica di un array

Modifichiamo un elemento già presente nell'array.

10. Ciclo for su array

Utilizziamo il ciclo for per leggere tutti gli elementi.

11. Ciclo for of su array

Utilizziamo il ciclo for of per leggere direttamente i valori.

12. Metodo map su array

Il metodo map crea un nuovo array modificando ogni elemento.

13. Metodo filter su array

Il metodo filter crea un nuovo array con gli elementi che rispettano una condizione.
